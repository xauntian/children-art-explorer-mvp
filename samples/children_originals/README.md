## 使用

在项目根目录执行；需要本地 ComfyUI 服务，生产流程不依赖 Ollama：

```powershell
.\.venv\Scripts\python.exe -m app.main import --photo samples/children_originals/01_garden.png --artwork
```

替换文件名即可使用另外两张。每个新任务会随机选择一次画派。

`--artwork` 用于已经包含完整画面的图片：跳过纸边检测、透视校正和裁边，完整图像等比放入当前 A4 画布，必要时补白，生成后输出短边 720 像素。第一张原图中的太阳、最右云团和蝴蝶已有边缘截断，导入保留原状。

这组图片已用于三种画派的 Prompt 与参数调试。当前目标是风格优先：原图提供主题或部分视觉线索，允许省略、合并、增补相关元素及改变构图和材质，不要求逐项复现。每种画派跨原图共用同一份画派摘要，不加入逐图场景描述。

当前 [八画派对照](../../examples/gallery.html) 保留二十四张选定结果及实际配方。生成 Prompt 为 1.7.0；正常流程只检查文件完整性并直接输出，主题与风格训练在流程外进行。当前生产随机池已启用全部八种；这些历史展示图不代表当前 FLUX.2 模型的质量验收。

图片来源为用户附件，作者年龄与绘制材料未经验证；不作为独立质量验收或儿童现场研究证据。项目现场创作材料仍以 MVP Spec 中的粗马克笔为准。

当前 FLUX.2 Klein 工作流采用 `crop=disabled`，完整原图作为图像参考，不进行模型侧中心裁切。生成服务、输出尺寸及操作方式见项目根目录 README.md。
